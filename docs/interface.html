Upscale — how to ask for a size

Every mode keeps the aspect ratio, and every mode works in both directions — set a value below the current size and it downscales.

Crop — the exact format

Off by default, so the node is a pure upscaler until you want a format. Switched on, it cuts a window out of the upscaled image — anchored with crop_position and nudged with crop_offset, the same controls as the JPS crop nodes.

Pick a classic format and the node takes the largest window of that shape that fits — crop_orientation flips it to portrait. Or set custom and type the pixels yourself.

It only ever cuts, never rescales, so nothing is resampled twice. If the window is larger than the upscaled image it is clamped to fit and the preview says so — raise the upscale until it covers.

Sockets

IMAGE LATENT STRING

image and samples are both optional — connect either or both. Each is sized from its own dimensions, so a latent never assumes it is the image divided by eight.

There is no model input socket: method = model is the default and upscale_model picks the file straight from your models/upscale_models folder — no separate loader node to wire up. One pass at the model's native scale, then one resize onto the target. Tiling is automatic and shrinks itself if VRAM runs short.
